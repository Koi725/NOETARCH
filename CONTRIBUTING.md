# Contributing to NOETARCH

Contributions are welcome once they respect the current governance-only phase.

1. Read `AGENTS.md`, `SECURITY.md`, and `coordination/STATUS.md`.
2. Select or propose a task in `coordination/TASKS.md` with explicit scope and acceptance criteria.
3. Do not add product features, secrets, unpinned executable dependencies, autonomous background behavior, or GitHub automation during this phase.
4. Keep changes focused and provide reproducible validation evidence.
5. Use the task, report, decision, and handoff templates under `agents/templates/`.
6. Report security concerns privately as described in `SECURITY.md`.

Agents may prepare changes but may not commit, push, merge, tag, release, delete branches, or change remotes. The CEO controls all Git mutations and decides whether a contribution is accepted.
