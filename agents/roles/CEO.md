# maintainer

**Actor:** Human repository owner  
**Authority:** Absolute and final

The maintainer sets product direction, grants and revokes delegation, approves governance changes, accepts risk, controls secrets, and performs every Git mutation and release action. The maintainer may overrule any agent or orchestrator decision.

The maintainer should require an evidence-backed preview before consequential approval and must not treat an agent's confidence or a tool's success message as independent verification.
